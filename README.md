
# ☕ Brew & Bloom

A modern, fully responsive restaurant and café website built using **HTML5**, **CSS3**, and **JavaScript**. Brew & Bloom delivers a clean, elegant user experience with a premium design that adapts seamlessly across desktop, tablet, and mobile devices.

---

## 🌐 Live Demo

🔗 https://gamma-j404.github.io/Coffe-Restaurant

---


---

## ✨ Features

- 📱 Fully Responsive Design
- 🍔 Featured Menu Section
- 📖 About Us Section
- ⭐ Customer Testimonials
- 🖼 Beautiful Gallery
- 📅 Reservation Form
- 📩 Contact Form (Formspree Integration)
- 🍃 Smooth Scrolling Navigation
- 🍔 Mobile Hamburger Menu
- 🎨 Modern UI with Hover Animations
- ⚡ Fast Loading & Optimized Layout

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/gamma-j404/brew-bloom.git
```

Open the project

```bash
cd brew-bloom
```

Run the website

Simply open `index.html` in your browser or use **Live Server**.
